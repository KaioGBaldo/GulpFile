# ⚡ Gulp Automation Workflow - Prática de Automação

Este projeto foca na otimização de performance e automação de tarefas repetitivas. Utilizando o **Gulp**, implementei um sistema que processa estilos, scripts e imagens automaticamente, garantindo um ambiente de desenvolvimento ágil e um produto final extremamente leve.

---

# 📝 Resumo (Resume)
O diferencial deste exercício foi sair do código visual e entrar na engenharia do projeto. Configurei um arquivo `gulpfile.js` que gerencia o ciclo de vida da aplicação: compilação de **SASS** para CSS, minificação e ofuscação de **JavaScript**, e a compressão pesada de **Imagens**. O resultado é uma pasta `/build` pronta para produção, com arquivos otimizados e mapas de depuração (sourcemaps).

## 📋 Funcionalidades em Destaque
* **Pipeline de Imagens:** Automação via `gulp-imagemin` que reduz o tamanho das fotos sem perda perceptível de qualidade.
* **Segurança e Minificação:** Uso de `gulp-uglify` e `gulp-obfuscate` para tornar o código JavaScript mais leve e protegido contra engenharia reversa.
* **SASS Workflow:** Organização de estilos com variáveis e módulos, compilados em tempo real com `gulp-watch`.
* **Lógica de Comparação:** Script funcional de comparação numérica (`compara.js`) integrado para validar inputs do usuário.
